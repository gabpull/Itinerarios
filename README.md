# Itinerario Japón · octubre 2026

Sitio estático para ver el viaje en el teléfono. No usa base de datos ni Node: SiteGround solo tiene que servir estos archivos.

## Subir a SiteGround

1. Entra a Site Tools del sitio.
2. Abre **Site** → **File Manager**.
3. Entra a `public_html` (o a la carpeta del subdominio, si quieres algo como `japon.tudominio.com`).
4. Sube el contenido de esta carpeta, no la carpeta vacía de alrededor:
   - `index.html`
   - `css/`
   - `js/`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon.svg`
5. Abre el dominio en el teléfono. En Chrome o Safari, usa **Agregar a pantalla de inicio**. La primera visita con internet guarda la página para abrirla después con mala señal.

También puedes subirlo por FTP a la misma carpeta `public_html`.

## Cómo se usa

- La flecha de arriba pasa al día anterior y la de abajo al siguiente.
- En la fecha se puede deslizar hacia arriba o hacia abajo para cambiar de día.
- La tira de números (5–24) salta a un día concreto.
- Cada actividad dice cuánto falta para la siguiente cuando las dos tienen hora. Si el PDF no trae hora, dice «A continuación» y no inventa un temporizador.
- **Cómo llegar** abre Google Maps en transporte público. **Ver en Maps** abre el lugar.
- Si abres el día que es **hoy en Japón**, un aviso marca dónde van y cuánto falta de verdad.
- **Guía** tiene hospedajes, entradas, pases, restaurantes, apps y frases.
